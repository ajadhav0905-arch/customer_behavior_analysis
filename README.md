# 📊 Data Analytics Project

## 📌 Project Overview

This project demonstrates an end-to-end data analytics workflow, starting from raw dataset loading to generating meaningful business insights through SQL and Power BI.

The main objective is to analyze data, identify patterns and trends, solve business problems, and present actionable insights using data visualization.

## 🎯 Project Objectives

- Load and understand the dataset using Python.
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess raw data.
- Execute SQL queries to extract meaningful insights.
- Build an interactive Power BI dashboard.
- Generate a professional analytical report.
- Prepare a PowerPoint presentation summarizing the findings.

## 🔄 Project Workflow

### 1. Data Loading
- Imported the dataset using Python.
- Used Pandas to load CSV/Excel files.
- Checked dataset dimensions and structure.

### 2. Exploratory Data Analysis (EDA)
- Analyzed rows, columns, and data types.
- Identified patterns, trends, and relationships.
- Generated statistical summaries.
- Created visualizations to understand the data.

### 3. Data Cleaning
- Handled missing values.
- Removed duplicate records.
- Corrected inconsistent data formats.
- Handled outliers where appropriate.
- Prepared clean data for further analysis.

### 4. SQL Analysis
- Connected the cleaned dataset to a SQL database.
- Created and executed SQL queries.
- Used filtering, aggregation, joins, subqueries, and window functions.
- Answered business-related questions using SQL.

### 5. Power BI Dashboard
- Imported the analyzed data into Power BI.
- Created relationships between tables.
- Developed DAX measures.
- Designed interactive visualizations.
- Added KPIs, charts, filters, and slicers.

### 6. Reporting & Presentation
- Documented important findings.
- Prepared an analytical report.
- Created a PowerPoint presentation.
- Summarized key insights and recommendations.

## ⚙️ How to Run the Project

### Prerequisites

Install Python and the required libraries:

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary
```

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/your-repository.git
```

### Step 2: Navigate to the Project

```bash
cd Data-Analytics-Project
```

### Step 3: Load the Dataset

Open Jupyter Notebook and execute the data-loading notebook.

```bash
jupyter notebook
```

### Step 4: Perform EDA and Data Cleaning

Run the Python notebooks in sequence.

### Step 5: Execute SQL Queries

- Create your database.
- Import the cleaned dataset.
- Execute the SQL scripts available in the SQL folder.

### Step 6: Open Power BI Dashboard

Open `Dashboard.pbix` using Microsoft Power BI Desktop.
